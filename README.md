# Garmin More Info

基于 `garmin_flower` 项目骨架初始化的 Connect IQ 表盘项目。

## 保留的能力

- 前台表盘与后台服务架构
- 设备 ID 展示和激活码设置
- 在线激活校验与本地激活状态缓存
- 单设备导出、商店包导出和批量设备测试脚本

## 主要入口

- `source/GarminMoreInfoApp.mc`：应用生命周期和后台激活校验
- `source/GarminMoreInfoView.mc`：表盘内容与样式，可在这里重新设计
- `source/LicenseManager.mc`：激活状态管理
- `resources/settings/`：设备 ID 与激活码设置项
- `monkey.jungle`：最小项目路径配置

## ORBIT DATA 表盘

当前表盘采用面向小圆屏的 ORBIT DATA 设计：

- OLED 黑色背景、醒目的大号时间和高对比酸性绿色数据
- 外圈以粗进度轨道显示手表电量
- 左右电量轨道各分为 8 段，段间留出细小黑色间隙；3 点和 9 点刻度处的间隙适当加宽，避免电量条与刻度重叠。高亮进度和灰色底轨采用相同分段，保留随电量变化的局部填充
- 下方四个数据槽可以由用户分别配置
- 每个槽均可选择步数、心率、身体电量、手表电量、卡路里或距离
- 布局按屏幕短边缩放，覆盖 208×208 至 454×454 的圆形屏幕
- `manifest.xml` 仅保留 Garmin SDK 标记为 `round` 的设备，矩形与 `semi-octagon` 异形屏已移除

四个数据槽可在 Garmin Connect / Connect IQ 的表盘设置中修改。身体电量在不提供该字段的旧设备上显示 `--`，不会影响其他数据。

设计参考稿位于 `design/orbit-data-concept-v2-small-screen.png`。

### 主题切换

目前共提供 21 款主题（11 款普通配色、10 款柔和撞色），设置列表先显示普通主题，再显示带「[撞色]」前缀的主题。新增普通配色：清透薄荷、柔雾玫瑰、奶油香草、鼠尾草绿、蜜桃珊瑚、长春花蓝；新增撞色：鼠尾草与玫瑰、雾蓝与奶油、蜜桃与长春花、水绿与丁香、藕粉与湖青、杏金与苔绿。新增主题沿用既有显示规则，已有主题的保存编号保持不变。

在 Garmin Connect / Connect IQ 的表盘设置中，选择「配色主题」并保存即可切换：经典荧光绿（默认）、冰川蓝、日落橙、薰衣紫、极简白。

另有四组柔和撞色主题：「[撞色] 雾青与暖杏」「[撞色] 薄荷与柔粉」「[撞色] 薰衣紫与奶油黄」「[撞色] 灰蓝与陶粉」。名称中的前一种颜色用于左侧手表电量条、日期和左列字段名称，后一种用于右侧身体电量条和右列字段名称；图标与名称旁的菱形跟随所在列配色，数据数值和刻度使用暖白色。原有五种单色主题保持原配色。

主题仅改变日期、外圈进度与刻度、数据数值、图标和菱形装饰的高亮色；背景、时间颜色、字体、位置、间距和数据槽布局保持不变。设置保存后刷新生效，重启后保留选择；旧用户或无效设置自动使用经典荧光绿。省电模式沿用原来的灰色显示。

### 电量条样式

在表盘设置的「电量条样式」中选择「分段展示」（默认）或「长实线」。两侧电量条同步切换，保存后刷新生效，重启保留选择。长实线取消细小分段间隙，两种样式均保留左右刻度线处的避让空隙；配色和布局不变。旧用户或无效设置默认使用分段展示。

## 构建

### College 字体

表盘设置新增「表盘字体」：College（默认）、Bree Serif、Gorditas、Lumberjack，均使用常规体。保存设置后刷新生效，重启保留选择；缺失或无效配置回退 College。切换影响时间、数值和英文日期/标签，中文和图标继续使用原字库。每次只加载所选字体，不同时加载四套。

时间、数据数值与英文日期/标签使用 `college.zip` 中的 College 常规体。中文与图标保留原字库。字体按 9 种屏幕分辨率生成，各机型仅打包对应尺寸；数据数值优先使用大号 College，空间不足时使用小号，极端情况下回退系统字体。

原始字体及授权说明位于 `assets/fonts/`。安装 Pillow 后，运行 `python scripts/generate_college_fonts.py` 可重新生成位图字体和 `monkey.jungle` 中的机型资源映射（需要本机 Garmin 设备 SDK）。

```powershell
.\scripts\Export-Device.ps1 -deviceId vivoactive5
```

验证全部圆形设备：

```powershell
.\scripts\Test-AllDevices.ps1 -Mode build -NoDedup
```

应用已使用独立 Connect IQ ID，不会覆盖 `garmin_flower`。
