# ORBIT DATA 多功能数据表盘｜Garmin 佳明 Connect IQ 表盘

## 产品介绍

ORBIT DATA 是一款专为 Garmin 圆形屏幕手表设计的多功能数字表盘。整体采用纯黑背景与高对比大数字时间，左右双半圆进度环包围表盘主体，四个数据区域集中展示日常运动与健康信息。无需反复翻页，抬腕即可快速查看时间、日期、电量及常用数据。

表盘提供多套单色与柔和撞色主题，并支持字体、数据名称样式、进度环样式和显示内容自由组合。无论偏爱醒目的运动风、简洁的黑白风，还是柔和的低饱和配色，都可以按照自己的习惯进行设置。

## 设计亮点

- **醒目大数字时间**：中央大字号显示时间，运动、通勤和户外场景下均可快速读取。
- **双半圆数据进度环**：左右半圆可分别显示手表电量、身体电量、压力或血氧，进度变化一目了然。
- **四个数据位自由配置**：左上、右上、左下、右下均可独立选择显示项目，打造属于自己的信息布局。
- **丰富数据支持**：可显示步数、心率、身体电量、手表电量、卡路里、距离、压力、血氧、海拔、气压和传感器温度；具体选项会根据手表能力自动适配。
- **21 套配色主题**：包含 11 套单色主题与 10 套柔和撞色主题，可轻松切换不同视觉风格。
- **4 款特色字体**：支持 College、Bree Serif、Gorditas、Lumberjack 四款字体。
- **3 种标签样式**：数据名称可选择简易英文、中文名称或小图标符号。
- **4 种进度环样式**：支持分段展示、长实线、更多分段和圆点样式。
- **多尺寸圆屏适配**：针对不同尺寸的 Garmin 圆形屏幕进行缩放与排版适配。

## 表盘显示内容

- 当前时间
- 日期与星期
- 左、右半圆进度数据
- 四个自定义数据位

四个数据位可选内容包括：

- 步数
- 心率
- 身体电量
- 手表电量
- 卡路里
- 距离
- 压力（0–100）

## 个性化设置

可在 Garmin Connect IQ App 的表盘设置中调整：

- 表盘字体
- 表盘主题色
- 进度环样式
- 数据标签样式
- 左侧半圆显示内容
- 右侧半圆显示内容
- 左上、右上、左下、右下四个数据项
- 激活码

修改后请点击保存，并保持手机与手表连接，等待设置同步。部分设备可能需要返回表盘、切换一次表盘或完成手动同步后才会刷新。

## 下载、安装与激活

1. 在手机应用商店安装 **Garmin Connect IQ**，并登录与手表绑定的 Garmin 账号。
2. 在 Connect IQ 中打开本表盘的下载页面，点击“安装”。
3. 保持手机蓝牙、网络以及 Garmin Connect / Connect IQ 的后台运行权限正常，等待表盘同步至手表。
4. 安装后进入 Connect IQ 的表盘设置，查看只读的“设备 ID”。
5. 将设备 ID 提供给卖家，获取与该设备对应的激活码。
6. 在“激活码”一栏中完整填写激活码并保存，再同步手表。
7. 激活校验需要网络连接，保存后请耐心等待数分钟；校验成功后即可正常使用。

## 使用须知

1. **本商品为数字内容**：商品仅包含 Garmin Connect IQ 表盘及对应使用授权，不包含图片中的手表、表带、手机或其他实体商品。
2. **购买前请确认兼容性**：仅支持已适配的 Garmin 圆形屏幕机型。下单前建议提供手表的完整型号，由卖家协助确认；仅提供系列名称可能无法准确判断。
3. **一个设备 ID 对应一个授权**：激活码与设备 ID 绑定。更换手表、主板或设备 ID 后，原激活码通常不能直接用于新设备，请在购买前确认授权规则。
4. **激活时需要联网**：请确保手机可正常联网，蓝牙连接正常，并允许 Garmin Connect / Connect IQ 在后台运行。网络不稳定时，激活状态可能不会立即刷新。
5. **数据以 Garmin 系统为准**：表盘只读取手表和 Garmin 系统提供的数据，不会代替手表进行测量，也不会修改原始健康数据。
6. **部分数据需要设备支持**：身体电量、压力、血氧、海拔、气压及传感器温度等功能取决于手表型号、硬件传感器、系统版本和测量设置。机型支持接口不代表任何时刻都有有效读数。
7. **出现 `--` 属于暂无数据**：若对应传感器未开启、尚未产生记录、佩戴时间不足或系统暂未提供有效值，表盘会显示 `--`，不代表表盘损坏。
8. **温度不是天气温度**：表盘中的“传感器温度”来自手表传感器，容易受到佩戴时的体温和环境影响，不等同于天气预报中的室外气温。
9. **显示效果可能略有差异**：不同机型的屏幕尺寸、分辨率、屏幕材质和系统渲染能力不同，实际字体大小、间距、颜色和边缘效果可能与宣传图存在轻微差异。
10. **设置项因机型而异**：为保证兼容性，数据选择列表会依据不同设备支持的接口自动生成，因此某些机型的可选项目可能少于宣传页面所列的完整项目。
11. **省电状态显示会简化**：手表进入低功耗或息屏模式后，表盘可能降低刷新频率、减少颜色或使用灰色显示，这是 Garmin 的省电机制及表盘适配效果。
12. **请勿将健康数据用于医疗判断**：心率、血氧、压力、身体电量等数据仅供日常运动与健康趋势参考，不能用于疾病诊断、治疗或紧急医疗判断。

## 常见问题

### Q：修改设置后为什么没有马上变化？

A：请先确认已经点击保存，并保持手机和手表蓝牙连接。可在 Garmin Connect 或 Connect IQ 中手动同步一次；如仍未刷新，可切换到其他表盘后再切回本表盘。

### Q：为什么某个数据选项在我的手表上找不到？

A：不同 Garmin 机型开放的数据接口不同。表盘会根据设备能力显示可用选项，不支持的字段不会出现在选择列表中。

### Q：为什么身体电量、心率、血氧等显示 `--`？

A：这表示手表暂时没有返回有效记录。请确认设备支持该功能、相关传感器或全天监测已开启，并正常佩戴一段时间后重新同步。

### Q：为什么半圆进度环没有亮起？

A：半圆所选数据当前没有有效读数时，只显示底部轨道。可在设置中改为手表电量，或等待对应健康数据产生后再查看。

### Q：输入激活码后仍提示激活怎么办？

A：请核对激活码是否完整、是否与当前设备 ID 对应，并确认手机网络和蓝牙正常。保存设置后手表会进行在线校验，通常需要等待数分钟；之后可手动同步或切换表盘刷新。

### Q：更换手表后还能继续使用原激活码吗？

A：激活码与设备 ID 绑定，更换设备后请联系卖家确认新设备的授权方式，原激活码通常不能直接通用。
